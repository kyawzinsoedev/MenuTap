# 🍽️ MenuTap – Dynamic Digital Menu & QR Ordering SaaS

MenuTap is a **multi-tenant SaaS platform** that enables restaurants to offer a **QR-based digital menu and contactless ordering experience**. Customers simply scan a QR code placed on their table to browse the menu and place orders directly from their mobile browser—no app installation or account registration required.

Designed with **Laravel + React + TypeScript**, MenuTap provides separate portals for Super Admins, Restaurant Owners, Staff, and Customers, making restaurant operations faster and more efficient.

---

## ✨ Features

### 👤 Customer Portal

* 📱 Mobile-first responsive interface
* 📷 Scan QR code to access the menu
* 🚫 No app installation required
* 🔐 No login required
* 🛒 Interactive shopping cart
* 🍽️ Browse menu by category
* 📦 Live order status tracking
* 🪑 Automatic table identification via QR code

### 🏪 Restaurant Portal

* 🍔 Dynamic menu management
* 📂 Category management
* 🖼️ Food image uploads
* 💲 Pricing & availability management
* 🪑 Table management
* 🔳 QR code generation for each table
* 🖨️ Printable QR labels
* 🔔 Real-time order notifications
* 👨‍🍳 Kitchen order dashboard
* 📋 Order status management
* 📊 Sales & order dashboard

### 👑 Super Admin Portal

* 🏢 Multi-tenant management
* 🛍️ Restaurant registration
* 🌐 Custom URL slug management
* 💳 Subscription management
* 📈 Business analytics dashboard
* 🔒 Tenant activation/deactivation
